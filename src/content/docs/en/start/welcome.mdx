# Level Up AI

**From Vibe Coder to AI Engineer.**

This project is an open, gamified learning path for anyone who wants to not just use AI, but understand and build with it. No course behind a paywall — just curated knowledge from the best free sources, organized into practical levels.

## How It Works

Each level consists of:

- **Briefing** — What you'll learn and why it matters
- **Theory** — The knowledge, explained concisely
- **Challenge** — Hands-on exercise with clear objectives
- **Solution** — Reference solution for comparison
- **Boss Fight** — An advanced task that combines everything

## Prerequisites

- Node.js 18+ and basic TypeScript knowledge
- An API key (Anthropic, OpenAI, or Google)
- Curiosity and willingness to break things
