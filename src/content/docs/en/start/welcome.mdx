## How It Works

Each level consists of **Briefing → Challenges → Boss Fight → Level Complete**.

Each challenge follows 6 steps:

1. **💭 THINK** — A question activates your prior knowledge
2. **🗺️ OVERVIEW** — A diagram shows the big picture
3. **❓ WHY** — The problem this concept solves
4. **📖 WALKTHROUGH** — Explained layer by layer, with annotated code
5. **🛠️ TRY** — Guided exercise with starter code and checklist
6. **🧩 COMBINE** — Connect the new concept with previous challenges

The **Boss Fight** at the end of each level combines all building blocks — without a pre-made solution.

## Prerequisites

- Node.js 18+ and basic TypeScript knowledge
- An API key (Anthropic, OpenAI, or Google)
- Experience with ChatGPT or similar AI tools
- Curiosity and willingness to break things
