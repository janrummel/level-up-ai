# Roadmap

## The Skill Tree

<Image src={skillTreeSvg} alt="Skill Tree: 9 levels from Vibe Coder to AI Engineer — Fundamentals (blue), Intermediate (green), Advanced (orange), Expert (red)" width={900} />

## Recommended Learning Paths

| Path | For whom | Levels |
|------|----------|--------|
| **Beginner** | No AI SDK experience | All levels in order (1–9) |
| **Advanced** | Already have AI SDK experience | 3, 5, 6, 8, 9 |
| **Agents & MCP** | Focus on agents and tools | 1, 3, 4, 8, 9 |
| **Production** | Focus on quality and robustness | 1, 5, 6, 7, 9 |

## Level Overview

- **[Level 1 — AI SDK Basics](../../level-1-ai-sdk-basics/01-briefing/)** (6 Challenges)
  Generate text, stream, structured output, system prompts
- **[Level 2 — LLM Fundamentals](../../level-2-llm-fundamentals/01-briefing/)** (4 Challenges)
  Tokens, context windows, usage tracking, prompt caching
- **[Level 3 — Agents & MCP](../../level-3-agents/01-briefing/)** (5 Challenges)
  Tool calling, MCP via stdio/HTTP, tool loop agent
- **[Level 4 — Persistence](../../level-4-persistence/01-briefing/)** (4 Challenges)
  Callbacks, chat IDs, database persistence, message validation
- **[Level 5 — Context Engineering](../../level-5-context-engineering/01-briefing/)** (5 Challenges)
  Prompt templates, exemplars, RAG, chain of thought
- **[Level 6 — Evals](../../level-6-evals/01-briefing/)** (5 Challenges)
  Evalite, deterministic evals, LLM-as-judge, Langfuse
- **[Level 7 — Streaming](../../level-7-streaming/01-briefing/)** (4 Challenges)
  Custom data parts, message metadata, error handling
- **[Level 8 — Workflows](../../level-8-workflows/01-briefing/)** (4 Challenges)
  Multi-step workflows, custom loops, frontend streaming
- **[Level 9 — Advanced Patterns](../../level-9-advanced/01-briefing/)** (4 Challenges)
  Guardrails, model router, output comparison, research workflow
