## Level-Uebersicht

- **[Level 1 — AI SDK Basics](/de/level-1-ai-sdk-basics/01-briefing/)** (6 Challenges)
  Text generieren, streamen, strukturierte Ausgaben, System Prompts
- **[Level 2 — LLM Fundamentals](/de/level-2-llm-fundamentals/01-briefing/)** (4 Challenges)
  Tokens, Context Windows, Usage Tracking, Prompt Caching
- **[Level 3 — Agents & MCP](/de/level-3-agents/01-briefing/)** (5 Challenges)
  Tool Calling, MCP via stdio/HTTP, Tool Loop Agent
- **[Level 4 — Persistence](/de/level-4-persistence/01-briefing/)** (4 Challenges)
  Callbacks, Chat-IDs, Datenbank-Persistenz, Message-Validierung
- **[Level 5 — Context Engineering](/de/level-5-context-engineering/01-briefing/)** (5 Challenges)
  Prompt Templates, Exemplars, RAG, Chain of Thought
- **[Level 6 — Evals](/de/level-6-evals/01-briefing/)** (5 Challenges)
  Evalite, deterministische Evals, LLM-as-Judge, Langfuse
- **[Level 7 — Streaming](/de/level-7-streaming/01-briefing/)** (4 Challenges)
  Custom Data Parts, Message Metadata, Error Handling
- **[Level 8 — Workflows](/de/level-8-workflows/01-briefing/)** (4 Challenges)
  Multi-Step Workflows, Custom Loops, Frontend-Streaming
- **[Level 9 — Advanced Patterns](/de/level-9-advanced/01-briefing/)** (4 Challenges)
  Guardrails, Model Router, Output-Vergleich, Research Workflow
