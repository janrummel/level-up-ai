# Level Up AI

**Vom Vibe Coder zum AI Engineer.**

Dieses Projekt ist ein offener, gamifizierter Lernpfad fuer alle, die AI nicht nur nutzen, sondern verstehen und bauen wollen. Kein Kurs hinter einer Paywall — sondern kuratiertes Wissen aus den besten freien Quellen, aufbereitet in praktischen Leveln.

## Dein Fortschritt

| Level | Thema | Challenges | Kern-Konzept |
|-------|-------|-----------|--------------|
| 1 | AI SDK Basics | 6 | generateText, streamText, Output API |
| 2 | LLM Fundamentals | 4 | Tokens, Context Window, Caching |
| 3 | Agents & MCP | 5 | Tools, Agent Loop, MCP Protocol |
| 4 | Persistence | 4 | Chat-Verlauf speichern und laden |
| 5 | Context Engineering | 5 | Prompt Templates, RAG, Chain of Thought |
| 6 | Evals | 5 | Evalite, LLM-as-Judge, Langfuse |
| 7 | Streaming | 4 | Custom Data Parts, Transforms, Errors |
| 8 | Workflows | 4 | Multi-Step Pipelines, Custom Loops |
| 9 | Advanced Patterns | 4 | Guardrails, Model Router, Production |

## Wie es funktioniert

Jedes Level besteht aus **Briefing → Challenges → Boss Fight → Level Complete**.

Jede Challenge folgt 6 Schritten:

1. **THINK** — Eine Frage aktiviert Dein Vorwissen
2. **OVERVIEW** — Ein Diagramm zeigt das Gesamtbild
3. **WHY** — Das Problem, das dieses Konzept loest
4. **WALKTHROUGH** — Schicht fuer Schicht erklaert, mit annotiertem Code
5. **TRY** — Gefuehrte Uebung mit Starter-Code und Checkliste
6. **COMBINE** — Verbinde das neue Konzept mit vorherigen Challenges

Die **Boss Fight** am Ende jedes Levels kombiniert alle Bausteine — ohne vorgefertigte Loesung.

## Voraussetzungen

- Node.js 18+ und TypeScript Grundkenntnisse
- Ein API Key (Anthropic, OpenAI, oder Google)
- Erfahrung mit ChatGPT oder aehnlichen AI-Tools
- Neugier und die Bereitschaft, Dinge kaputt zu machen
