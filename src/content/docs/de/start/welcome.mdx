## Wie es funktioniert

Jedes Level besteht aus **Briefing → Challenges → Boss Fight → Level Complete**.

Jede Challenge folgt 6 Schritten:

1. **💭 THINK** — Eine Frage aktiviert Dein Vorwissen
2. **🗺️ OVERVIEW** — Ein Diagramm zeigt das Gesamtbild
3. **❓ WHY** — Das Problem, das dieses Konzept loest
4. **📖 WALKTHROUGH** — Schicht fuer Schicht erklaert, mit annotiertem Code
5. **🛠️ TRY** — Gefuehrte Uebung mit Starter-Code und Checkliste
6. **🧩 COMBINE** — Verbinde das neue Konzept mit vorherigen Challenges

Die **Boss Fight** am Ende jedes Levels kombiniert alle Bausteine — ohne vorgefertigte Loesung.

## Voraussetzungen

- Node.js 18+ und TypeScript Grundkenntnisse
- Ein API Key (Anthropic, OpenAI, oder Google)
- Erfahrung mit ChatGPT oder aehnlichen AI-Tools
- Neugier und die Bereitschaft, Dinge kaputt zu machen
